## 0 目的与门禁

验证本轮改版是否从"认出科目"推进到"能产出日英财务表达"，并确认错答可恢复、反馈自解释。

| 门禁 | 必须 PASS | 明确不作为 P0 merge gate |
|---|---|---|
| P0 merge | T-A1, T-B1, T-B2, T-B3, T-B4 | 词源（etymology）、完整 ASR 评分 |
| P1 | T-C1, T-E1（+ UI 语言冒烟可选记） | 词源完善度 |
| P2 | T-D1（证明"可选且不挡"） | — |

**成功定义（P0）**：用户能撤销/再试一次错答且看到正确配对；能看到 JA|EN 并排卡；能打出 EN；能朗读对照自查；能完成一张面试模板卡（第一人称 + 追问 + {vars}）。

**非目标**：本清单不要求词源内容写全；缺词源不得判 P0 FAIL。

## 2 用例

| 项 | 内容 |
|---|---|
| 对应 | PRD US-1 · Track A |
| 步骤 | 1）进入链条拼搭（匹配或 P&L 排序）或测验。2）故意点错一步。3）寻找 Undo 或"再试一次"。4）纠正为正确操作。5）确认本轮未因"仅一次误触"直接终局失败（或槽位未被首次错误吃光）。6）**确认放错后可见"正确配对 / 差异说明"（非只有无声 `❌`）** |
